# Creating Custom Themes

## Theme Structure
```json
{
    "name": "ocean-dark",
    "background": "#0d1117",
    "text": "#c9d1d9",
    "accent": "#58a6ff",
    "border": "#30363d",
    "statsBar": "#238636"
}
```

## Adding a New Theme
1. Create theme object in `themes/` directory
2. Register in theme registry
3. Add preview screenshot
4. Submit PR
